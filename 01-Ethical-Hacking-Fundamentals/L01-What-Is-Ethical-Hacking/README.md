o	What This Lesson Covers
•	What ethical hacking actually is
•	The difference between ethical hackers and malicious hackers
•	The six stages of an ethical hacking assessment
•	Common tools used at each stage
•	What beginners should focus on first

o	Key Points
1. Ethical hacking is authorised security testing
2. Permission must come before any testing starts
3. The process follows a logical sequence
4. Tools are chosen based on what you're trying to do
5. Ethical hackers help organisations fix problems
