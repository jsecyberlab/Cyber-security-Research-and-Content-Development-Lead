Example Answer Structure

1. Definition of Ethical Hacking
Ethical hacking is the practice of testing computer systems, networks, and applications for security weaknesses with the permission of the owner. The goal is to identify vulnerabilities before malicious attackers can exploit them. Ethical hackers follow a structured methodology, stay within defined scope, and produce professional reports documenting their findings.

2. Five Ethical Rules
1. Always obtain written permission before testing.
2. Stay within the defined scope of the assessment.
3. Do no harm to the systems being tested.
4. Maintain confidentiality of all information discovered.
5. Report all findings honestly and professionally.

3. Vulnerability vs Exploit
Vulnerability: A weakness in a system, like an unpatched software bug or misconfigured firewall.
Exploit: A technique or tool that takes advantage of a vulnerability to gain unauthorised access or cause an effect.
Example: An outdated web server running on a system is a vulnerability. The Metasploit module that uses that vulnerability to gain access is an exploit.
